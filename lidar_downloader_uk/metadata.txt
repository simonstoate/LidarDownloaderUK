description=Download UK LIDAR data straight into QGIS

about=Ground and surface height models (DTM and DSM), point clouds and aerial photos (as available) from each government's official open data service: the Environment Agency, DataMapWales and the Scottish Remote Sensing Portal. Choose your area on the map, pick the data, and the plugin downloads, organises and loads it for you. Northern Ireland's LIDAR can't be downloaded through the plugin yet, so it links to the official data on OpenDataNI instead. This is an independent plugin, not affiliated with or endorsed by any of these organisations.

changelog=
    0.15.0
          - Go to replaces the selection with the place's tiles.
          - The grid fades when zoomed out.
          - All of the Welsh archive, with sizes estimated from real files.
          - Survey dates for Welsh DTMs and DSMs.
          - New users: a one-time tip, and zips deleted once extracted.
          - Point cloud tiles of several files show their points (QGIS 3.44+).
          - Scotland: "newest for each tile" picks a survey that covers the whole tile.
          - Scotland: Phase 1 and 2's 10 km files only for the tiles they reach.
          - The grid shows newly published surveys.
          - Real plurals in messages, and a Feedback link.
    0.14.6
          - Each 5 km tile loads as one layer, read straight from the downloaded files.
          - Only Create mosaic and Crop to join tiles.
          - A simpler, shorter panel.
          - After downloading: load each tile, load a temporary mosaic, or just download.
          - Crop to: downloads only the tiles a polygon needs.
          - Fixes: data menu, Northern Ireland links, night photos, Welsh archive heights.
    0.14.5
          - Removed the deprecated supportsQt6 metadata flag.
    0.14.4
          - Passes the plugin site's Qt6 compatibility check.
    0.14.3
          - First public release (development history: CHANGELOG.md in the repository).
